# Applaio

Applaio is a Windows desktop application for tracking job applications and recruitment processes.

## Direction

- Windows 11-first desktop UX
- WinUI 3 + Windows App SDK
- .NET 10 LTS / C# 14
- Mica/Acrylic glass-style interface
- modular architecture with explicit Domain, Application, Infrastructure and Desktop layers
- local-first persistence with SQLite
- import/migration pipeline for spreadsheet data
- testable business logic independent from the UI

The first real dataset will be migrated from the owner's existing recruitment-tracking Excel workbook.
