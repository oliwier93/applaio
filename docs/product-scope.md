# Product scope

## Primary goal

Replace a manually maintained recruitment spreadsheet with a desktop application that makes the current state of every job application immediately visible.

## Core workflow

A recruitment entry should ultimately capture:

- company,
- role,
- offer/source URL,
- source/platform,
- application date,
- current stage/status,
- contract type,
- compensation/rate,
- recruiter/contact,
- next action,
- next action date,
- interview history,
- notes,
- rejection/withdrawal reason,
- documents/CV version used.

The exact initial fields will be refined from the supplied Excel workbook.

## UX direction

The main recruitment experience should support both:

- a dense sortable/filterable list for fast work,
- a visual pipeline/Kanban-like view by recruitment stage.

Dashboard candidates:

- active recruitments,
- applications sent this week/month,
- upcoming interviews/follow-ups,
- waiting for response,
- offers,
- conversion between stages.

No analytics definition should be finalized until the migrated workbook has been inspected.
